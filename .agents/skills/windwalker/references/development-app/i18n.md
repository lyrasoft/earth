# i18n / 多語系指引

在 `windwalker/unicorn` 新增或修改可翻譯文字時使用。

- 公開文件：<https://windwalker.io/documentation/components/language/index.md>
- 新增、改名或重用鍵前，必讀專案內 instructions & docs 內的命名指引。

## 可用機制

- 語言檔：`resources/languages/<locale>/unicorn.ini`，語系為 `en-US`（備援）與 `zh-TW`。
- 查找順序：目前語系 → 備援 → 父層。找不到時回傳鍵本身；除錯模式顯示 `??key??`。
- 安裝：`UnicornPackage` 以 `lang` 標籤複製到宿主 `resources/languages`，宿主可覆寫。

## 鍵名

- 以 `app.` 開頭，小寫點分段，依領域分組（`app.field.*`、`app.message.*`、`app.title.*` 等）。
- 不用 `_`、`-`、camelCase 區分，會被正規化成相同鍵。
- 不由使用者輸入組鍵；動態後綴只能來自封閉集合，且每個值都要有對應鍵。

## 語言檔（`.ini`）

- 格式：`key="value"`，UTF-8，值以雙引號包住；值內字面 `"` 寫 `\"`，位置參數字串中字面 `%` 寫 `%%`。
- 佔位符：具名 `:name`（`trans('k', name: $v)`）或位置式 `%s`/`%d`，同一字串只擇一；各語系佔位符需相同。
- 值可含 HTML，但需刻意為之。
- 刪除或改名鍵屬破壞性變更，先搜尋使用處。

## 後端（PHP）

- 容器類別用 `TranslatorTrait`（`trans()`、`choice()`）或注入 `LangService`；不要 `new LangService` / `new Language`。
- 具名參數必須以名稱傳入（`trans('k', name: $v)`），陣列作第二參數無效。
- 複數用 `choice()`；不翻譯的文字用 `raw()`；可選鍵用 `LangService::has()` 判斷。
- `FormFieldsBuilder` 產生的標籤依 `$this->trans('<key>')` 契約，需維持。

## 發送至前端（TypeScript / Vue）

- PHP 匯出：`$unicornScript->translate('key')`、`translate(['a.b'])`、`translate('prefix.*')`。
- TS 讀取：`__('key', max)`（位置式）或 `__('key', { title })`（具名），定義於 `assets/src/service/lang.ts`。
- `__()` 使用的每個鍵，都需由載入該模組的 PHP 路徑匯出：全域在 `UnicornScript::main()`，模組專用在對應腳本類別（如 `FormScript`）。
- 新增前端字串需同時完成：兩語系 ini + `translate()` + `__()`。
- 整組鍵優先用萬用字元；除非整組已匯出，不得以執行期組成的鍵呼叫 `__()`。
- 不硬寫使用者可見文字；不把機密或未跳脫 HTML 放入語言字串。
- `assets/dist/` 為建置產物，勿手動編輯。

## 驗證

- 比對多個語言鍵集合是否一致。
- 搜尋使用處：`grep -r "app.some.key" src views assets/src`。
- 以 `LANG_DEBUG=1` 檢查頁面是否出現 `??key??`（PHP 缺鍵或 JS 缺 `translate()` 匯出）。
- 再次比對所有語言鍵是否嚴格遵循命名規則。
